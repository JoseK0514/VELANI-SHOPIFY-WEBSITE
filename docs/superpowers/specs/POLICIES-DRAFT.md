## Cookies and choices — draft

The website uses Shopify and may use necessary storage for security, privacy choices and platform operation. Publish an inventory of the actual cookie/storage categories and providers after inspecting the final website.

Optional analytics, marketing and preference integrations must be identified separately and connected to the supported consent mechanism. No new optional integration is authorized by this draft.

Visitors must be able to open Cookie choices from the footer, understand the categories, accept or reject optional processing where applicable, and change their choices. Necessary processing is explained. Controls must work with keyboard and assistive technology.

Use Shopify's Customer Privacy API and its supported consent behavior; never edit its cookies directly. Save consent only in response to the visitor's choice. Honor applicable opt-out signals through verified implementation. If the privacy API does not load, do not start optional integrations as a fallback.

Consent withdrawal must update the relevant integrations prospectively. State verified behavior and provider limits accurately; do not promise that withdrawing consent erases all previously processed data.
